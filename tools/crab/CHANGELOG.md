# Change Log

## 0.0.4

- Highlight terminal/file input, parsing, and text-processing built-ins.

## 0.0.3

- Add named/anonymous fun functions, return statements, Unit and function types.
- Highlight callable record fields, function calls, and return arrows.
- Treat print as a built-in and highlight higher-order/math/string built-ins.

## 0.0.2

- Highlight collection built-ins, type annotations, ranges, and collection punctuation.
- Add square bracket matching and single-quoted string support.
- Recognize `in` loops and highlight `!=` as a comparison operator.

## 0.0.1

- Initial syntax highlighting and language configuration.
